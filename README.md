# KeyGlow v5

Windows用のキーボード入力可視化ツールです。音楽ゲームなどのキー入力を、発光・縦に流れる入力履歴・タップグラフで表示し、OBSのブラウザソースに追加できます。

4鍵／5・6鍵／8鍵に対応し、各位置の検知キーを実際のキー入力で変更できます。同時押し・長押しに対応しています。

## 1. 必要なもの

- Windowsの通常のデスクトップ環境（macOS・Linux非対応）。
- Python 3.10以上。`python` コマンドで起動できる必要があります。
- JavaScriptが利用できる新しいブラウザ。
- 配信・録画に使う場合は、ブラウザソースが利用できるOBS Studio。

Python以外の追加ライブラリや、pipでのインストールは不要です。Pythonは同梱していません。未導入の場合はPython公式サイトからWindows用Pythonを導入し、ターミナルで `python --version` が表示されることを確認してください。

## 2. 起動する

1. ZIPで受け取った場合は、フォルダー全体を展開します。
2. 設定を書き込める場所（ドキュメントなど）にフォルダーを置きます。
3. `Start.cmd` をダブルクリックします。
4. ブラウザで設定画面が開きます。開かない場合は、起動したまま次のURLを開いてください。

設定画面： http://127.0.0.1:18964/

起動した黒いウィンドウは開いたままにしてください。最小化は可能です。ブラウザの設定画面を閉じても、起動ウィンドウが動いていれば検知とOBS表示は続きます。

`index.html` を直接開くのではなく、Start.cmdで起動した上で設定画面へアクセスしてください。

## 3. 配列を選ぶ

「ゲームのキー配列」で使う配列を選びます。標準の並びは左から次の通りです。

| 配列 | 左補助 | ゲームキー（左 → 右） | 右補助 |
| --- | --- | --- | --- |
| 4鍵 | 左Shift | A・S ／ ；・： | 右Shift |
| 5・6鍵 | 左Shift | A・S・D ／ L・；・： | 右Shift |
| 8鍵 | 左Shift | A・S・D・C ／ 、・L・；・： | 右Shift |

「／」は中央の区切りで、割り当てキーではありません。5・6鍵は共通の表示プリセットです。8鍵ではDの内側にC、Lの内側に「、」が入ります。

標準は日本語JIS配列を想定しています。「、」は「ね」の刻印があるカンマキーです。画面によって「；」「：」を半角の「;」「:」で表示します。

### 検知キーを変更する

1. 変更する配列を選び、「検知キーをカスタマイズ」を開きます。
2. 変更したい位置の「変更」ボタンをクリックします。
3. 「キーを押してください…」と表示されたら、割り当てたいキーを1つ押します。
4. 必要な位置を変更し、「割り当てを保存」をクリックします。

保存するまでは実際の検知に反映されません。入力待ちは「キー入力をキャンセル」で取り消せます。Esc自体も割り当て可能です。別のウィンドウに移ると入力待ちは解除されます。

- 配列ごとに別の割り当てを保存できます。同じ配列内で同じキーを複数位置に割り当てることはできません。
- 英数字、対応する記号、F1～F12、矢印、テンキー、Space・Enterなどに対応します。Shift・Ctrl・Altは左右を区別します。
- 複数キーの組み合わせを1つの位置には割り当てられません。マウスやゲームパッドは対象外です。
- OSやブラウザが先に処理するキーは登録できない場合があります。テンキーはNum Lockをオンにして登録・使用してください。通常のEnterとテンキーEnterは同じキーとして扱います。
- キーの名前はJIS基準です。別配列では刻印と表示名が違うことがあるため、保存後に発光する位置を確認してください。
- 「標準に戻す」は、選択中の配列を標準の割り当てへ戻して保存します。
- 保存した割り当ては、起動中のOBSにも自動反映されます。

両端の位置は「補助キー」です。別のキーを割り当てても、両端は打鍵間隔や全体平均の集計対象から除外されます。補助キーの押下時間自体は記録します。

## 4. OBSに表示する

1. KeyGlowを起動し、配列・表示モード・表示する時間・発光カラーを設定します。
2. 設定画面の「OBSに追加」でURLをコピーします。
3. OBSのソースで「＋」から「ブラウザ」を追加します。
4. 「ローカルファイル」をオフにし、コピーしたURLを貼り付けます。
5. 幅と高さを、設定画面に表示された値に合わせます。

| 表示モード | 幅 | 高さ |
| --- | ---: | ---: |
| 入力履歴 ＋ キー発光 | 360 | 1080 |
| 入力履歴のみ | 360 | 1080 |
| キー発光のみ | 1100 | 180 |
| タップグラフ（OBS用） | 900 | 800 |

キー表示の背景は透過です。入力履歴・グラフには見やすさのための半透明背景があります。

配列・表示モード・時間・色を変更した場合は、変更後のURLをOBSへ貼り直してください。検知キーの割り当てだけを変更した場合は貼り直し不要です。複数の表示を使う場合は、別々のブラウザソースとして追加できます。

OBSはKeyGlowと同じPCで使用してください。このURLを別のPCから開くことはできません。

## 5. 表示・停止操作

### 入力履歴とキー発光

入力履歴は下の「NOW」が現在で、過去の入力が上へ流れます。線の長さが押していた時間です。表示範囲は直近2秒／4秒／8秒から選べます。補助キーの履歴は紫色です。

キー発光は、離してから約90ms残ります。履歴とタップ詳細はこの余韻を含まず、検知した押下・解放時刻を使います。

「履歴を止めて見る」でその画面だけ固定し、「ライブに戻す」で再開します。発光テスト・履歴デモ・グラフデモは見た目の確認用で、実入力の記録には入りません。デモが動いても、実際の入力検知が成功しているとは限りません。

### 一時停止と終了

- `Ctrl + Alt + F12`：入力検知の一時停止／再開。すべての表示に適用され、ライブ履歴は消去されます。
- 「記録を停止」／「記録を再開」：タップ詳細の記録だけを停止／再開します。キー発光とライブ履歴は続きます。
- 「KeyGlowを終了」、`Stop.cmd`、または起動ウィンドウを閉じる：アプリを終了します。

終了するとメモリ内の記録は消えます。必要な記録は先に出力してください。

## 6. タップ詳細・グラフ・出力

起動時から自動で記録します。設定画面の表には直近15打鍵、グラフには直近30／100／300打鍵を表示できます。グラフは約0.25秒ごとに更新し、キーで絞り込めます。横軸は等間隔の打鍵番号、縦軸はミリ秒です。点にマウスを重ねると値を確認できます。

グラフ固定は表示だけを止めます。固定やデモは操作した画面だけに適用され、他の画面や記録には影響しません。

| 指標 | 意味 |
| --- | --- |
| 押下時間 | 押してから離すまで |
| 次の打鍵まで | 押してから、次の補助キー以外の打鍵まで |
| 離してから次まで | 離してから次の打鍵まで。負の値は押し重なり |
| 同じキーの次まで | 同じキーを再び押すまで |
| 同時押し数 | 同じ検知周期で押された、補助キー以外のキー数 |

同じ検知周期の同時押しは1つのグループとし、その後の異なる時刻の打鍵を「次」とします。平均打鍵間隔はグループごとに1回集計します。全体の平均押下時間・平均ギャップからは補助キーを除外します。

未確定・対象外・中断で計算できない値は「—」、CSVでは空欄、JSONではnullです。記録停止・入力一時停止・割り当て保存をまたぐ打鍵間隔は計算しません。記録途中で中断した押下には、解放時刻を補いません。

### CSV／JSONに保存する

「全記録をCSV出力」または「全記録をJSON出力」をクリックします。表の15件だけでなく、現在の配列に含まれる記録全体を出力します。CSVはUTF-8 BOM付き、JSONには集計・キー別統計・指標の説明も含まれます。

最大50,000打鍵で記録を停止します。「新しい記録（現在の記録を消去）」で消去して再開できます。必要なら消去前に出力してください。

**割り当て変更後は、過去の記録も現在の割り当てで絞り込み・集計されます。変更前の結果を残したい場合は、変更前に出力してください。**

出力データの主な項目（時間はすべてms）：

| 項目 | 内容 |
| --- | --- |
| id / key | 打鍵番号／検知したキー名 |
| segment / status | 連続した記録の区間／完了・押下中・中断の状態 |
| press_ms / release_ms | 最初の記録から押下／解放までの経過時間 |
| hold_ms | 押下時間 |
| chord_size | 同時押し数（補助キーは対象外） |
| next_keys / next_press_ms | 次のキー名／次の打鍵までの時間 |
| release_to_next_ms | 離してから次の打鍵までの時間 |
| same_key_next_ms | 同じキーの次の押下までの時間 |

## 7. 設定とデータの保存場所

- キー割り当て：アプリと同じフォルダーの `key-bindings.json`。初めて保存すると作成され、再起動後も復元します。
- 配列・色・表示モード・時間：設定画面を開いたブラウザ内に保存します。別ブラウザでは共有されません。OBSにはURLで渡します。
- 入力履歴：直近12秒程度（完了した入力は最大4,096件）と押下中の情報をメモリに保持します。
- タップ記録：最大50,000打鍵をメモリに保持します。自動で履歴ファイルには保存しません。
- CSV／JSON：ブラウザで指定したダウンロード先に保存します。

検知・記録するのは、3つの配列に設定されたキーすべての和集合です。選択していない配列のキーも記録対象です。一時停止用ショートカットも検知します。ゲーム以外のウィンドウを操作中でも対象キーを検知するため、不要なときは一時停止または終了してください。

アプリの通信は同じPC内の `127.0.0.1:18964` だけで行い、入力情報を外部へ送信しません。

## 8. 困ったとき

**Start.cmdが起動しない／Pythonが見つからない**

Python 3.10以上を導入し、ターミナルで `python --version` を確認してください。ZIP内から直接起動せず、全ファイルを展開してください。起動ウィンドウに表示されるエラーも確認してください。

**設定画面が開かない／「未接続」と表示される**

Start.cmdの起動ウィンドウが動いているか確認してください。自動で開かないときは設定画面のURLを手動で開きます。ポート18964が使用中の場合は、起動中のKeyGlowや競合するアプリを確認してください。

**押しても光らない**

選択中の配列と保存済みの割り当てを確認し、入力が一時停止中ならCtrl + Alt + F12で再開してください。「対象キーの受信回数」が増えるかも確認してください。通常のWindowsデスクトップからStart.cmdを起動してください。隔離されたデスクトップでは動作せず、ログイン画面やUAC画面の入力も対象外です。

ゲーム中だけ検知されない場合は、そのゲームの入力方式や起動権限との組み合わせにより検知できない可能性があります。すべてのゲームでの動作は保証しません。

**キーを登録できない／意図したキーと違う**

設定画面を手前に出し、変更ボタンをクリックしてからキーを1つ押してください。非対応キーやOSが優先するキーは登録できない場合があります。JIS以外の配列では刻印と表示名が異なる場合があります。テンキーはNum Lockをオンにして確認してください。

**割り当てを保存できない**

同じ配列内でキーが重複していないか、アプリのフォルダーに書き込めるかを確認してください。新しいファイルへ更新した場合は、起動中の旧版を終了してからStart.cmdを起動し直してください。

**OBSに出ない／更新が反映されない**

設定画面からURLをコピーし直し、幅・高さを確認してください。OBSのブラウザソースでページのキャッシュを更新してください。アプリの更新後はKeyGlowを再起動し、設定画面も再読み込みしてください。

**記録が増えない**

記録停止中・入力一時停止中でないか確認してください。50,000打鍵に達した場合は、必要な記録を出力してから「新しい記録」で再開してください。

## 9. 計測できること・できないこと

これは実際のキー操作の可視化ツールです。ゲームの譜面、判定、押せなかったノート、BPMや拍位置は取得せず、音声やゲーム画面の解析も行いません。

約2ms間隔を目安にWindowsのキー状態を確認しますが、実際の間隔はPCの負荷などで変わります。非常に短い入力を取り逃す場合があり、キーボード本体の同時押し制限も解消できません。小数3桁の出力は書式であり、マイクロ秒単位の精度を示すものではありません。ゲーム内の判定時刻との一致は保証しません。

検知はキー単位です。複数の物理キーボードを接続した場合、どの機器からの入力かは区別しません。

## 10. 配布・更新時のファイル

次のファイルを同じフォルダーに入れて配布してください。

- Start.cmd / Stop.cmd
- server.py / metrics.py / keyconfig.py
- index.html
- bindings.js / trail.js / metrics-ui.js / graphs.js
- README.md または README.txt

`key-bindings.json` は省略できます。省略すると標準配列で起動します。同梱すると、その割り当てを配布先でも使います。`__pycache__` と `test_keyconfig.py` は通常の利用には不要です。出力済みのCSV／JSONは必要な場合だけ同梱してください。

更新前に必要なタップ記録を出力し、KeyGlowを終了してください。自分の割り当てを残す場合は `key-bindings.json` を保管し、更新後も同じフォルダーに置きます。更新後はStart.cmdで起動し直し、設定画面とOBSを再読み込みしてください。
